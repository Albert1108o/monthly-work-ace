# Time Keeper

faça uma aplicação que permita o usuario inserir as horas trabalhadas por dia, os dias trabalhados e por fim some a quantidade de horas trabalhadas no mês, faça por meio de um banco sqlite usando php, faça tambem um dockerfile e compose que contenha todas as ferramentas necessarias para a aplicação
